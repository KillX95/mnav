        Clé API Google Maps manquante

        Le moteur Leaflet · OSM fonctionne sans clé API. Pour activer Google Maps, ajoutez votre clé dans le fichier config.js : 

        window.MNAV_CONFIG = {
  googleMapsApiKey: "VOTRE_CLE_ICI",
  defaultLocation: { lat: 48.8566, lng: 2.3522 }
};

        Créez une clé sur Google Cloud Console, activez Maps JavaScript API, Places API et Directions API, puis restreignez-la par HTTP referrer.
